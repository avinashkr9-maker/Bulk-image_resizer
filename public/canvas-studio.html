How to use Canvas Studio:
1. Load one reference image and position it exactly where you want on the canvas.
2. Use the Scale slider or mouse wheel to zoom in or out.
3. Drag the image to position it - guides show center, collar and hem lines.
4. Select your target folder and click Render Batch.
5. All images in the folder will use the exact same position and scale.
